## 自动检查

`source-inventory.json` 记录迁移基线中每个源码/文档/资源的 SHA-256，不包含凭据与缓存。
`pnpm test` 检查全部基线文件存在、未经适配的文件内容一致，并测试登录 fragment、刷新令牌和失效状态。
适配过的文件白名单位于 `tests/migration.test.mjs`；文档和静态资源没有适配豁免。
