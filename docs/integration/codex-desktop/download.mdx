# 第3步 Codex 桌面端下载与安装
Codex桌面端不仅适合程序员做代码阅读、代码修改、测试和代码审查；也适合营销、运营、产品、咨询、研究、财务、法务和管理岗位处理方案、周报、竞品资料、活动脚本、SOP、表格、批量文档和知识库整理。

:::important[下载说明]
ChatGPT 已经和 Codex 合并为同一个软件。本页面提供的 Windows 和 macOS 下载会每天同步更新，下载后即可获得对应系统的最新版本。
:::

## 下载前先判断系统
为了方便大家使用，HackStart 为大家提供每天同步更新的 Codex 桌面端软件安装包，方便网络环境不好的同学下载使用。不过在下载前，需要先确认要下载哪个版本。

| 系统 | 你要确认什么 | 推荐安装包 |
| --- | --- | --- |
| macOS Apple Silicon | 芯片是 M1、M2、M3、M4 或更新的 Apple 芯片 | Apple Silicon DMG |
| macOS Intel | “关于本机”里显示 Intel Processor | Intel DMG |
| Windows | Windows 10 / 11，常见 Intel / AMD 电脑 | 官方安装器 EXE |


macOS 查看芯片的方法：点击左上角 Apple 图标 -> 关于本机。如果看到 Apple M 系列，选 Apple Silicon；如果看到 Intel，选 Intel。

## macOS Apple Silicon 下载

适用于 M1、M2、M3、M4 等 Apple Silicon Mac，推荐使用每天同步更新的加速下载地址。

- Apple Silicon Mac：[https://codexapp.agentsmirror.com/latest/mac-arm64](https://codexapp.agentsmirror.com/latest/mac-arm64)，推荐下载这个，无需科学就能下载
- 腾讯云镜像：[Codex-mac-arm64.dmg](https://hackweek-1251009918.cos.ap-shanghai.myqcloud.com/codex/Codex-mac-arm64.dmg)，如上面的下载地址速度不理想，可以使用这个备用镜像
- OpenAI 官方文件：[Codex.dmg](https://persistent.oaistatic.com/codex-app-prod/Codex.dmg)，网络环境比较OK能上外网的同学，可以下载这个链接

下载完软件安装包后，会看到软件的后缀是`dmg`格式，然后双击打开 DMG，把 Codex 拖到 Applications / 应用程序，从启动台或 Applications 打开 Codex。如果系统提示“来自互联网下载”，确认打开。如果系统阻止启动，进入 系统设置 -> 隐私与安全性，允许打开 Codex。

不要把 DMG 改成中文文件名，也不要放在包含特殊符号的目录里。安装完成后可以删除 DMG，但不要删除 Applications 里的 Codex。

## macOS Intel 下载
如果你的Mac电脑比较旧，可能使用的还是Intel芯片，这里的安装包适用于 Intel 芯片 Mac。推荐使用每天同步更新的加速下载地址。

- Intel Mac：[https://codexapp.agentsmirror.com/latest/mac-intel](https://codexapp.agentsmirror.com/latest/mac-intel)，推荐下载这个，无需科学就能下载
- 腾讯云镜像：[Codex-mac-intel.dmg](https://hackweek-1251009918.cos.ap-shanghai.myqcloud.com/codex/Codex-mac-intel.dmg)，如上面的下载地址速度不理想，可以使用这个备用镜像
- OpenAI 官方文件：[Codex-latest-x64.dmg](https://persistent.oaistatic.com/codex-app-prod/Codex-latest-x64.dmg)，网络环境比较OK能上外网的同学，可以下载这个链接

安装步骤和 Apple Silicon 基本一致：下载 Intel DMG，下载完软件安装包后，会看到软件的后缀是`dmg`格式，双击打开。拖入 Applications / 应用程序。打开 Codex。如被系统拦截，到 系统设置 -> 隐私与安全性 允许打开。

如果你把 Apple Silicon 版本装到了 Intel Mac，通常会出现打不开、闪退或提示架构不匹配。删除错误版本后重新安装 Intel 版即可。

## Windows 下载

Windows 版本适用于常见的 Intel / AMD 64 位电脑。推荐使用每天同步更新的 Windows x64 下载地址：

- Windows x64：[https://codexapp.agentsmirror.com/latest/win-x64](https://codexapp.agentsmirror.com/latest/win-x64)
- 腾讯云镜像：[Codex-Windows-x64.msix](https://hackweek-1251009918.cos.ap-shanghai.myqcloud.com/codex/Codex-Windows-x64.msix)，如上面的下载地址速度不理想，可以使用这个备用镜像

下载安装包后，按照安装程序提示完成安装。如系统提示安全确认，请确认来源后再允许。

## 第一次打开要做什么？
你只需要确认Codex可以正常打开进入到官方账号或API选择的界面即可，先不要用官方账号登录，也不要做API的选择，然后直接强制退出Codex。Mac用户强制关闭窗口即可，Windows用户不仅要关闭窗口，注意小托盘里面的也要关闭。接下来去下载CC Switch，它非常方便你做Codex的配置（不会对Codex造成破坏）。

Codex 桌面端接入 HackStart 的关键不是下载安装，而是下一步的 Provider 配置。请继续阅读 [Codex 配置与 CC Switch](/docs/integration/codex-desktop/cc-switch)。
