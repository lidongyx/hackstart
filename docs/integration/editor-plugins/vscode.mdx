# VS Code 插件配置

这一页适用于支持 OpenAI Compatible Provider 的 VS Code 插件。不同插件界面不同，但配置项大体一致。

## 下载 VS Code

如果你还没有 VS Code：

- 官方下载：[https://code.visualstudio.com/Download](https://code.visualstudio.com/Download)

macOS：

1. 下载对应芯片版本。
2. 打开安装包。
3. 把 Visual Studio Code 放到 Applications。
4. 打开 VS Code。

Windows：

1. 下载 User Installer 或 System Installer。
2. 运行安装器。
3. 建议勾选 Add to PATH。
4. 安装后打开 VS Code。

## 安装插件

1. 打开 VS Code。
2. 点击左侧 Extensions / 扩展。
3. 搜索你要使用的 AI 插件，例如 Cline、Roo Code、Continue 或团队指定插件。
4. 点击 Install。
5. 安装后重启 VS Code，或按插件提示打开侧边栏。

尽量从 VS Code Marketplace 安装，不要从不明来源下载 `.vsix` 文件。AI 插件会接触项目代码和 API Key，来源必须可信。

## 配置 HackStart Provider

进入插件设置，寻找以下字段：

```text
Provider
API Provider
OpenAI Compatible
Custom OpenAI
Base URL
API Key
Model
```

通用填写：

```text
Provider: OpenAI Compatible
Name: HackStart
API Key: sk-...
Base URL: https://ip2.hackstart.org/v1
Model: gpt-5.5
```

如果插件要求分别填写 Host 和 Path：

```text
Host: https://ip2.hackstart.org
Path: /v1
```

如果插件已经固定拼接 `/v1`，就只填：

```text
https://ip2.hackstart.org
```

如果报错里出现 `/v1/v1`，说明重复加了 `/v1`。

## Cline / Roo Code 类 Agent 插件

这类插件通常会请求读取文件、修改文件或执行命令。建议配置：

```text
API Provider: OpenAI Compatible
Base URL: https://ip2.hackstart.org/v1
API Key: HackStart API Key
Model ID: gpt-5.5
```

第一次任务建议输入：

```text
请阅读当前工作区，概括项目结构。不要修改文件，不要运行命令。
```

当插件要求执行命令时，先看清楚命令。例如：

```bash
pnpm test
pnpm typecheck
pnpm build
```

这些通常是合理的检查命令。遇到删除文件、上传文件、部署、重置 Git 的命令，先停下来确认。

## Continue 类补全插件

Continue 这类插件通常使用配置文件或设置页配置模型。概念上类似：

```json
{
  "models": [
    {
      "title": "HackStart GPT",
      "provider": "openai",
      "model": "gpt-5.5",
      "apiBase": "https://ip2.hackstart.org/v1",
      "apiKey": "sk-..."
    }
  ]
}
```

不同版本字段名可能叫 `apiBase`、`baseUrl` 或 `apiBaseUrl`。以插件当前文档为准，但值仍然是 HackStart 的 OpenAI Compatible 地址。

## 测试方式

打开一个测试项目，在插件聊天窗口输入：

```text
请解释当前打开文件的作用。不要修改文件。
```

成功标准：

1. 插件能读到当前文件。
2. 能正常返回解释。
3. HackStart 控制台出现请求记录。
4. 没有自动修改文件。

## 常见问题

### 插件一直要求 OpenAI 官方 Key

确认插件是否支持 OpenAI Compatible / Custom Base URL。有些插件只支持官方账号，不能接入 HackStart。

### 插件支持 Base URL 但仍然失败

检查：

```text
https://ip2.hackstart.org/v1
```

是否写成了：

```text
https://ip2.hackstart.org/v1/
https://ip2.hackstart.org/v1/v1
https://ip2.hackstart.org
```

最后一个在普通 OpenAI Compatible 插件里通常不对，除非插件自己固定添加 `/v1`。

### 插件能聊天但不能改文件

这通常是插件权限或模式问题。检查是否开启 Agent 模式、是否授权工作区写入、是否选择了正确工作区。

### 插件运行命令失败

先在 VS Code 终端手动运行同一命令。如果手动也失败，说明是项目环境问题，不是 HackStart API 问题。
