# Cursor 与其它编辑器

Cursor、JetBrains 系列、Zed、Sublime Text 等编辑器也可能通过插件或内置设置接入 OpenAI Compatible API。只要它允许自定义 API Key 和 Base URL，就可以尝试使用 HackStart。

## 通用判断

能接入 HackStart 的前提：

1. 支持 OpenAI Compatible。
2. 支持自定义 Base URL。
3. 支持自定义模型名。
4. 不强制只使用官方账号登录。

如果某个编辑器只允许你登录它自己的账号，不提供自定义 API 地址，就不能直接按本文档接入。

## 通用配置

```text
Provider: OpenAI Compatible
API Key: sk-...
Base URL: https://ip2.hackstart.org/v1
Model: gpt-5.5
```

有些编辑器把模型分成 Chat Model、Edit Model、Apply Model、Embedding Model。新人先只配置 Chat / Edit 相关模型，不要急着配置 Embedding。

## Cursor 注意事项

Cursor 的不同版本、不同功能对自定义模型的支持程度可能不同。你需要在设置里寻找：

```text
Models
OpenAI API Key
Override OpenAI Base URL
Custom Models
```

如果当前版本不支持某项自定义能力，可以选择：

1. 更新 Cursor。
2. 使用 VS Code + 插件。
3. 使用 Codex 桌面端。
4. 使用 Cherry Studio 做普通聊天。

不要为了接入 API 去下载来源不明的修改版编辑器。

## JetBrains 注意事项

JetBrains 插件生态里有多种 AI 插件。配置时重点看：

1. 是否支持 OpenAI Compatible。
2. Base URL 是否可改。
3. API Key 是否保存在本机安全存储。
4. 是否会把项目内容发送给第三方服务。

如果插件只支持官方 OpenAI 或插件作者自己的云服务，就不能直接使用 HackStart。

## 测试任务

无论你用哪个编辑器，第一次都做只读测试：

```text
请解释当前打开文件的作用，不要修改任何文件。
```

再做小范围修改：

```text
请只在当前文件中添加必要注释，不要修改其它文件。
```

最后检查 git diff，确认插件没有改到无关文件。

## 编辑器插件的成本习惯

- 开启自动补全会产生更多请求，先观察用量。
- 大型仓库索引可能消耗较多额度。
- Agent 模式比普通聊天更容易多轮请求。
- 给编辑器插件单独创建 API Key，设置额度上限。
- 不使用时可以禁用插件或切换到低成本模型。
