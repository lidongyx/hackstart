# Codex CLI 安装

Codex CLI 适合习惯终端的人。它可以在项目目录或资料目录里读取文件、修改内容、运行命令和协助排错，也适合远程服务器、脚本化工作流、批量文件处理、数据整理和高级办公自动化任务。

如果你还不熟悉命令行，建议先完成 [Codex 桌面端](/docs/integration/codex-desktop/download)，再回到这一章。

## 安装前准备

先确认本机有 Node.js、npm 和 npx：

```bash
node --version
npm --version
npx --version
```

如果这些命令不存在，先安装 Node.js。

## macOS 安装 Node.js

推荐使用 Homebrew：

```bash
brew install node
node --version
npm --version
npx --version
```

如果你还没有 Homebrew，可以到 [brew.sh](https://brew.sh/) 按官方命令安装。公司电脑如果限制安装，请联系管理员，或使用 Node.js 官方安装包。

## Windows 安装 Node.js

推荐两种方式任选一种。

方式一：Node.js 官方安装包

1. 打开 [Node.js 官网](https://nodejs.org/)。
2. 下载 LTS 版本。
3. 运行安装器。
4. 勾选自动添加到 PATH。
5. 安装后重新打开 PowerShell。
6. 运行：

```powershell
node --version
npm --version
npx --version
```

方式二：winget

```powershell
winget install OpenJS.NodeJS.LTS
```

安装后重新打开 PowerShell，再验证版本。

## Linux 安装 Node.js

Ubuntu / Debian 可以先尝试：

```bash
sudo apt update
sudo apt install -y nodejs npm
node --version
npm --version
npx --version
```

如果系统源版本太旧，使用 NodeSource 或你们团队标准的 Node.js 安装方式。远程服务器上不要随便用 root 全局安装大量包，先确认团队规范。

## 安装 Codex CLI

不同版本和环境里的安装命令可能会变化。新人建议优先从 [OpenAI Codex CLI 官方文档](https://developers.openai.com/codex/cli) 或你们团队给出的命令安装。安装完成后，用版本命令验证：

```bash
codex --version
```

如果提示 `command not found`：

1. 关闭终端重新打开。
2. 检查 npm global bin 是否在 PATH 中。
3. Windows 检查安装目录是否加入环境变量。
4. 如果你使用 npx 方式运行，确认命令写法和官方文档一致。

## Mac 终端选择

macOS 默认 Shell 通常是 zsh。后续环境变量可以写在：

```text
~/.zshrc
```

如果你使用 bash，则写在：

```text
~/.bashrc
```

不确定自己用什么 Shell，可以运行：

```bash
echo $SHELL
```

## Windows 终端选择

Windows 推荐 PowerShell。后续配置文件通常在：

```text
%userprofile%\.codex\
```

如果你使用 WSL，请把 WSL 当成 Linux 环境处理。不要把 Windows 项目路径、WSL 项目路径、Windows Node 和 Linux Node 混在一起，否则容易出现找不到文件、权限异常或命令不可用。

## 先不要写 API Key

安装完成后先只验证 CLI 是否存在：

```bash
codex --version
```

确认命令可用后，再进入下一页 [Codex CLI 配置 HackStart](/docs/integration/codex-cli/configuration)。不要一边安装一边改 API Key，否则出了问题很难判断是安装问题还是配置问题。
