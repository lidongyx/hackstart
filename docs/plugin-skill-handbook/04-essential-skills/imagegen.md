# imagegen

`imagegen` 用于生成或编辑位图资产，例如照片、插画、纹理、sprites、mockup 和透明背景素材。

## 适合场景

- 网站封面图。
- 产品 mockup。
- 游戏素材。
- 社交媒体图片。
- 图片风格变体。

## 典型提示词

```text
$imagegen
请生成一张用于插件与技能小册首页的封面图，风格清爽、技术感，不要包含文字。
```

## 使用边界

如果任务更适合用 SVG、HTML/CSS 或现有图标系统实现，就不要用 imagegen。
