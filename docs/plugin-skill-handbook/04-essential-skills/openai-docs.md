# openai-docs

`openai-docs` 用来查询 OpenAI 和 Codex 官方文档。凡是涉及“当前 Codex 到底怎么工作”的内容，都应该优先用它核对。

## 适合场景

- 查询 Codex 插件、skills、MCP、配置。
- 查询 OpenAI API 参数和示例。
- 写教程时引用官方定义。
- 做模型和提示词升级。

## 典型提示词

```text
$openai-docs
请根据官方文档解释 Codex skill 和 plugin 的区别，并给出适合团队分发的建议。
```

## 实践建议

不要凭记忆写“最新行为”。只要和 Codex 产品能力、OpenAI API、模型选择有关，就让 Codex 查官方文档。
