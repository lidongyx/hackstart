# 最值得优先学习的技能

技能比插件更贴近“怎么做事”。下面这些技能值得优先掌握，因为它们能直接改善日常工作质量。

## 系统技能

| 技能 | 用途 |
| --- | --- |
| skill-creator | 创建和改进自己的技能 |
| plugin-creator | 把技能和工具打包成插件 |
| skill-installer | 安装官方 curated skills 或其他仓库技能 |
| openai-docs | 查询 OpenAI/Codex 官方文档 |
| imagegen | 生成或编辑位图视觉资产 |

## 工程和产品技能

| 技能 | 用途 |
| --- | --- |
| playwright | 浏览器自动化和前端 QA |
| cli-creator | 为 Codex 打造可复用 CLI |
| figma | 读取 Figma 设计上下文和截图 |
| figma-implement-design | 从 Figma 到生产代码 |
| chatgpt-apps | 构建 ChatGPT Apps SDK 应用 |
| ui-ux-pro-max | UI/UX 审查、设计建议和界面改造 |

## 交付类技能

| 技能 | 用途 |
| --- | --- |
| cloudflare-deploy | Cloudflare 部署 |
| vercel-deploy | Vercel 部署 |
| netlify-deploy | Netlify 部署 |
| render-deploy | Render 部署 |
| speech | 文本转语音 |
| transcribe | 音视频转写 |

后面的文章会逐个介绍这些技能如何触发、什么时候用、怎么写提示词。
