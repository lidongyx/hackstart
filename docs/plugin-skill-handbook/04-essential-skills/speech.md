# speech

`speech` 用于文本转语音，适合生成旁白、产品演示音频、无障碍朗读和批量语音素材。

## 适合场景

- 视频旁白。
- 产品介绍语音。
- IVR 或提示音。
- 批量生成音频文件。

## 典型提示词

```text
$speech
请把这段产品介绍生成一段 30 秒左右的中文旁白音频。
```

## 实践建议

明确语言、语速、语气、输出格式和保存目录。不要把 API key 发给 Codex，让它读取本机环境变量。
