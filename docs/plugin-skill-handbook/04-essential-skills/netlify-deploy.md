# netlify-deploy

`netlify-deploy` 用于 Netlify 静态站点和 Web 应用部署。

## 适合场景

- 静态站点部署。
- 预览部署。
- 检查 build command 和 publish directory。
- 连接现有 Netlify site。

## 典型提示词

```text
$netlify-deploy
请检查这个静态站点能否部署到 Netlify，先给出 build 命令、发布目录和预览部署计划。
```

## 实践建议

先 preview，再 production。确认环境变量、重定向规则和构建产物目录。
