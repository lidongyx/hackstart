# figma-implement-design

`figma-implement-design` 专门用于把 Figma 设计翻译成生产代码。它强调先获取设计上下文和截图，再按项目技术栈实现。

## 适合场景

- 根据 Figma 页面实现前端。
- 将组件设计落到代码组件。
- 对比设计稿和实现效果。
- 修复视觉还原偏差。

## 典型提示词

```text
$figma-implement-design
请根据这个 Figma 链接实现对应页面，先获取设计上下文和截图，再对照项目现有组件落地。
```

## 验证方式

实现后要求 Codex 用浏览器截图和 Figma 截图对照，检查间距、字号、颜色、交互状态和响应式布局。
