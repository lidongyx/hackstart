# ui-ux-pro-max

`ui-ux-pro-max` 适合 UI/UX 审查、界面改造、设计系统建议和风格探索。它更像一个设计顾问技能。

## 适合场景

- 审查页面信息层级。
- 改进表单、导航、仪表盘。
- 选择颜色、字体、图表形式。
- 做设计系统规则。
- 给前端页面提出可落地修改。

## 典型提示词

```text
$ui-ux-pro-max
请审查这个后台仪表盘，重点看信息密度、扫描效率、按钮层级和移动端布局。
```

## 实践建议

让它输出可执行修改建议，而不是抽象审美评价。最好要求按 P0/P1/P2 排优先级。
