# Google Drive 插件

Google Drive 插件适合读取和整理团队文件、Google Docs、Sheets、Slides 等资料。它常用于“资料散在很多文件里，但你需要一个结论”的场景。

## 适合场景

- 查找项目相关文档。
- 汇总多个 Google Docs 的内容。
- 从 Drive 找最新版方案、会议材料或客户资料。
- 把资料整理成 brief、报告或任务清单。

## 典型提示词

```text
@Google Drive
请查找和 HackStart 接入教程相关的最新文档，列出文件名、更新时间和可能相关的章节。
```

## 使用建议

告诉 Codex 查找范围、关键词和时间窗口。不要让它在整个 Drive 里无边界搜索。

## 风险边界

Drive 里可能有合同、人事、财务资料。涉及敏感文件时，先只让 Codex列文件和摘要，不要复制全文。
