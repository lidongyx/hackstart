# Documents 插件

Documents 插件适合创建、编辑和检查文档类交付物，比如 `.docx`、项目备忘录、报告草稿和面向 Google Docs 的文档内容。

## 适合场景

- 把会议纪要整理成正式文档。
- 生成项目方案、PRD、说明书。
- 编辑 `.docx` 文件。
- 检查文档排版和导出质量。

## 典型提示词

```text
请使用 Documents 插件，把这份提纲整理成一份正式项目方案文档，包含背景、目标、范围、里程碑和风险。
```

```text
请读取这个 Word 文档，保留原结构，帮我把语气改得更适合对客户发送。
```

## 实践建议

文档类任务不要只要求“写得好”。最好给 Codex：

- 读者是谁。
- 文档用途。
- 语气风格。
- 必须保留的标题结构。
- 是否需要可打印或可交付文件。

如果文档要正式交付，要求 Codex 做一次渲染或视觉检查。
