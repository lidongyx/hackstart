# Presentations 插件

Presentations 插件适合制作和修改演示文稿，包括 PowerPoint、Google Slides 风格的 deck、汇报稿和课程幻灯片。

## 适合场景

- 把研究内容做成汇报 deck。
- 根据大纲生成 PPTX。
- 修复已有幻灯片的结构和视觉。
- 为产品发布、融资、教学准备演示材料。

## 典型提示词

```text
请使用 Presentations 插件，把这份产品方案做成 10 页演示文稿，面向非技术管理层。
```

```text
请检查这个 PPTX，每页给出标题、核心信息和视觉问题，然后修复排版。
```

## 好的输入

给 Codex 做 deck 时，最好说明：

- 听众是谁。
- 演讲时长。
- 页数范围。
- 是否偏商务、技术、教学或销售。
- 每页是否需要 speaker notes。

不要只说“做一个好看的 PPT”。越具体，结果越稳。
