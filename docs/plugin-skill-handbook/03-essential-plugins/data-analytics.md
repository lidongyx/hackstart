# Data Analytics 插件

Data Analytics 是面向数据分析、业务判断、报表和仪表盘的插件方向。它适合把 Codex 从“写 SQL 或画图”提升到“带证据做分析”。

## 适合场景

- 分析 CSV、Excel、数据库导出。
- 解释指标为什么变化。
- 做 KPI 周报、月报、经营分析。
- 建仪表盘或分析报告。
- 做市场规模、机会评估、产品业务判断。

## 典型提示词

```text
@Data Analytics
请分析这份订单 CSV，找出最近 30 天收入下降的主要驱动因素，并用图表和表格支持结论。
```

```text
@Data Analytics
请帮我设计一个 SaaS 增长仪表盘，包含北极星指标、驱动指标、护栏指标和更新频率。
```

## 和 Spreadsheets 的区别

Spreadsheets 负责做表格文件本身，Data Analytics 负责分析问题、选择指标、解释变化和生成报告。可以这样组合：

1. Spreadsheets 清洗和整理数据。
2. Data Analytics 做诊断、洞察和图表。
3. Documents 或 Presentations 生成最终报告。

## 好输入

数据分析任务要尽量提供：

- 数据文件或表结构。
- 指标定义。
- 时间范围。
- 对比基准。
- 你真正要做的决策。

不要只说“帮我分析一下”。好的分析一定围绕问题和决策展开。
