# Remotion 插件

Remotion 插件适合维护 React 视频工程。相比 HyperFrames，它更适合已有 React 组件、批量视频模板和工程化视频生成。

## 适合场景

- 已有 Remotion 项目。
- React 组件化视频模板。
- 数据驱动批量生成视频。
- 修复 composition、fps、时长和渲染问题。

## 典型提示词

```text
@Remotion
请检查这个视频项目，修复 composition 尺寸和时间轴问题，并说明渲染命令。
```

## 怎么选

已有 React/Remotion 项目就用 Remotion。只是想快速做 HTML 风格产品视频，优先看 HyperFrames。
