# HyperFrames 插件

HyperFrames 插件适合用 HTML、CSS、时间线和动画生成视频。它尤其适合产品演示、社交媒体短视频和网站转视频。

## 适合场景

- 产品介绍视频。
- 网站录屏转宣传视频。
- 字幕、标题卡、转场。
- 音频驱动视觉效果。

## 典型提示词

```text
@HyperFrames
请把这个网站做成一个 20 秒产品介绍视频，包含开场、功能展示和结尾 CTA。
```

## 实践建议

先确定脚本、镜头和节奏，再写动画。视频任务最怕一上来就写代码，最后叙事散掉。
