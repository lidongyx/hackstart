# Zotero 插件

Zotero 插件适合连接你的本地文献库，查找论文、导出 BibTeX、插入引用和整理阅读清单。

## 适合场景

- 搜索 Zotero 文献库。
- 导出 `references.bib`。
- 给草稿添加引用 key。
- 根据研究主题推荐已收藏论文。

## 典型提示词

```text
@Zotero
请搜索我库里关于 transformer interpretability 的论文，导出 BibTeX，并推荐 5 篇最相关的。
```

## 组合流程

研究写作中常和 LaTeX、PDF 插件组合：Zotero 找引用，LaTeX 编译，PDF 检查输出页面。
