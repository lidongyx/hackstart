# Zoom 插件

Zoom 插件适合处理会议上下文，也适合构建 Zoom API、SDK、Webhook 和自动化集成。

## 适合场景

- 搜索最近会议里讨论过的主题。
- 从会议记录整理行动项。
- 准备会前 brief。
- 构建 Zoom App、bot、API 集成或 webhook。

## 典型提示词

```text
@Zoom
请搜索最近两周关于 pricing 的会议内容，整理成决策、争议点和待办事项。
```

```text
@Zoom
请帮我规划一个 Zoom webhook 集成，先列出事件、鉴权方式和本地调试步骤。
```

## 实践建议

会议资料容易包含敏感信息。让 Codex 输出摘要和行动项即可，未经确认不要转发原始会议内容。
