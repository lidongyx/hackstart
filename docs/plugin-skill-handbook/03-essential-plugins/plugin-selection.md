# 最值得优先学习的插件

插件不必全装。对大多数 Codex 用户，优先学习下面这些就足够覆盖 80% 的扩展场景。

## 第一梯队：几乎人人有用

| 插件 | 适合任务 |
| --- | --- |
| Browser | 本地网页测试、Docusaurus/React/Vite 页面检查 |
| Chrome | 需要已有登录态、浏览器扩展、真实 Chrome 状态的网页任务 |
| Computer Use | 控制本机桌面应用，处理浏览器之外的 GUI 工作 |
| Documents | 生成和编辑 Word/Google Docs 风格文档 |
| Spreadsheets | 处理 Excel、CSV、Google Sheets 交付 |
| PDF | 阅读、提取、生成和视觉检查 PDF |
| Presentations | 制作 PowerPoint/Google Slides 风格演示文稿 |

## 第二梯队：开发和发布强相关

| 插件 | 适合任务 |
| --- | --- |
| Product Design | 产品设计、界面审查、从想法到原型 |
| Data Analytics | 数据分析、仪表盘、报告、KPI 和业务判断 |
| Vercel | Next.js、Web 应用部署与 Vercel 工作流 |
| Browser/Playwright 组合 | 前端交互测试和截图验证 |
| LaTeX | 论文、研究报告、复杂排版 |
| Zotero | 文献管理、BibTeX、引用插入 |

## 第三梯队：垂直场景

| 插件 | 适合任务 |
| --- | --- |
| HyperFrames | HTML 视频、产品演示、短视频制作 |
| Remotion | React 视频工程 |
| Zoom | 会议上下文、Zoom API/SDK 集成 |
| Airtable | 运营数据表、轻量数据库、业务流程 |
| Gmail | 邮件阅读、草拟回复、客户跟进 |
| Google Drive | 文件、文档和团队资料上下文 |
| Slack | 频道总结、行动项、团队沟通 |
| Zoom | 会议上下文、Zoom API/SDK 集成 |
| Airtable | 运营数据表、轻量数据库、业务流程 |
| Codex Security | 安全扫描和漏洞修复工作流 |
