# Gmail 插件

Gmail 插件适合让 Codex 处理邮件上下文：查找邮件、总结未读内容、整理客户跟进、草拟回复。它的关键边界是：草拟可以自动化，发送必须谨慎确认。

## 适合场景

- 汇总今天未读邮件。
- 找出客户、供应商或团队成员的关键邮件。
- 从邮件线程提取行动项。
- 草拟回复、跟进、道歉、确认或会议安排邮件。
- 按紧急程度整理收件箱。

## 典型提示词

```text
@Gmail
请找出今天来自客户的未读邮件，按紧急程度排序，并为每封邮件草拟回复。不要发送。
```

## 权限边界

默认让 Codex 只读和草拟。发送、归档、删除、移动标签等动作都应先停下来等你确认。

## 验证方式

要求 Codex 列出邮件主题、发件人、时间和它依据的判断，不要只给模糊总结。
