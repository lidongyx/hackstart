# PDF 插件

PDF 插件适合读取、提取、生成和视觉检查 PDF。它特别适合“布局重要”的任务，因为 PDF 不能只看文本，还要看页面渲染效果。

## 适合场景

- 提取 PDF 里的文字和表格。
- 检查合同、报告、论文排版。
- 生成正式 PDF。
- 把扫描件或复杂页面转成结构化信息。
- 对比 PDF 修改前后的视觉差异。

## 典型提示词

```text
请使用 PDF 插件读取这个 PDF，提取目录和每章摘要，并指出可能的排版问题。
```

```text
请把这份 Markdown 内容排版成 PDF，并渲染检查每页是否有文字溢出。
```

## 实践建议

PDF 任务要强调“视觉检查”。只抽文本往往会漏掉：

- 表格错位。
- 页眉页脚遮挡。
- 图片缺失。
- 字体乱码。
- 分页不合理。

正式交付前，让 Codex 渲染页面截图并检查关键页。
