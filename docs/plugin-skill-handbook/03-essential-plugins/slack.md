# Slack 插件

Slack 插件适合把频道、私信和线程里的讨论整理成可执行信息。它常用于项目推进、客服、销售、运营和团队协作。

## 适合场景

- 汇总某个频道过去一周的讨论。
- 提取决策、阻塞问题和待办事项。
- 草拟频道回复或公告。
- 根据 Slack 讨论更新文档或任务清单。

## 典型提示词

```text
@Slack
请汇总这个项目频道过去一周的关键决策、阻塞问题和待办事项。只读取，不要发送消息。
```

## 安全边界

发送消息、@人、创建频道、归档频道之前都要人工确认。默认让 Codex 只读和草拟。

## 好输出

好的 Slack 总结应该包含：来源频道、时间范围、关键结论、负责人、待确认问题和建议下一步。
