# 技能设计模式

常见技能包括检查清单型、报告型、转换型、部署型、审查型和工具封装型。

## 官方内容整理

- 常见技能包括检查清单型、报告型、转换型、部署型、审查型和工具封装型。
- 检查清单型强调步骤和验收。报告型强调来源、分析框架和交付格式。
- 转换型强调输入输出映射。部署型强调命令、平台、回滚和验证。
- 工具封装型常与 CLI 或 MCP 配合，让 Codex 稳定调用外部能力。

## 实践补充

- 先选择一个主模式，不要让一个 skill 处理所有事情。
- 把失败处理和人工确认点写清。
- 真实运行后根据误用情况调整触发描述。

## 推荐工作流

1. 先明确任务目标、输入来源和允许 Codex 使用的工具。
2. 让 Codex 输出计划、风险边界和需要你确认的问题。
3. 从小范围样例开始，确认方向后再扩大。
4. 要求 Codex 保留证据、文件路径、截图、命令输出或验证结果。
5. 对发送、删除、付款、发布、提交、部署等动作保持人工确认。
