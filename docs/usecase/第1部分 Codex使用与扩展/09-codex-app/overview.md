# Codex App 总览

![Codex App 桌面端界面](https://md-1251009918.cos.ap-shanghai.myqcloud.com/hackstart/codex-docs/images-codex-app-codex-app-basic-light.webp)

Codex App 是一个专注于 Codex 线程协作的桌面端工作中心。它支持并行处理多个线程、内置 worktree、自动化和 Git 功能。

## 官方内容整理

- Codex App 是一个专注于 Codex 线程协作的桌面端工作中心。它支持并行处理多个线程、内置 worktree、自动化和 Git 功能。
- 它既适合代码任务，也适合长时间运行的资料整理、报告生成、测试验证和跨工具工作流。
- ChatGPT Plus、Pro、Business、Edu 和 Enterprise 计划都包含 Codex 能力，具体可用功能会随账号和工作区策略有所不同。
- macOS 和 Windows 都可以使用 Codex App，多数功能跨平台一致；少数功能存在平台限制。

## 实践补充

- 把 Codex App 理解成“项目命令中心”：项目、线程、终端、审查、浏览器、自动化和插件都在这里协同。
- 简单任务用 Local；需要隔离或并行探索时用 Worktree；需要远程环境时再考虑 Cloud。
- 国内用户通常先完成 HackStart API 配置，再用小任务验证模型、权限和网络。

## 推荐工作流

1. 先明确任务目标、输入来源和允许 Codex 使用的工具。
2. 让 Codex 输出计划、风险边界和需要你确认的问题。
3. 从小范围样例开始，确认方向后再扩大。
4. 要求 Codex 保留证据、文件路径、截图、命令输出或验证结果。
5. 对发送、删除、付款、发布、提交、部署等动作保持人工确认。

## 示例提示词

```text
请先帮我判断这个任务适合用 Local、Worktree 还是 Cloud。说明原因、影响范围、验证方式，以及是否需要先创建独立工作树。
```
