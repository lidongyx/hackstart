# 内置浏览器

![Codex 内置浏览器](https://md-1251009918.cos.ap-shanghai.myqcloud.com/hackstart/codex-docs/images-codex-app-in-app-browser-light.webp)

内置浏览器让你和 Codex 在同一线程中查看渲染后的网页，适合本地开发服务器、文件预览和无需登录的公共页面。

## 官方内容整理

- 内置浏览器让你和 Codex 在同一线程中查看渲染后的网页，适合本地开发服务器、文件预览和无需登录的公共页面。
- 它不支持登录流程、已有浏览器 profile、cookie、扩展或已有标签页。需要登录态时应使用普通浏览器或 Chrome 扩展。
- Browser use 可以让 Codex 操作内置浏览器：点击、输入、截图、检查页面状态、下载资源和运行只读页面检查。
- 你可以在页面上进入 Annotation 模式，选择元素或区域留下评论，再让 Codex 修复。
- Developer mode 可让 Codex 在明确批准下使用 CDP 检查 DOM、样式、网络和性能。

## 实践补充

- 本地前端调试先用内置浏览器，登录态任务再用 Chrome 扩展。
- 视觉问题最好用页面评论标注具体元素，不要只用文字描述。
- 每次浏览器任务都要限定路由、状态和修改范围。

## 推荐工作流

1. 先明确任务目标、输入来源和允许 Codex 使用的工具。
2. 让 Codex 输出计划、风险边界和需要你确认的问题。
3. 从小范围样例开始，确认方向后再扩大。
4. 要求 Codex 保留证据、文件路径、截图、命令输出或验证结果。
5. 对发送、删除、付款、发布、提交、部署等动作保持人工确认。

## 示例提示词

```text
请用内置浏览器打开本地页面，复现移动端布局问题。根据我留在页面上的评论修复，只处理被标注区域，完成后重新截图检查。
```
