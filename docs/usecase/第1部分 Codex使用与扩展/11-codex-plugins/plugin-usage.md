# 安装和使用插件

![Codex CLI 插件浏览](https://md-1251009918.cos.ap-shanghai.myqcloud.com/hackstart/codex-docs/images-codex-plugins-cli_light.png)

在 App 中可以打开 Plugins 浏览和安装插件；CLI 中也可以打开插件列表。

## 官方内容整理

- 在 App 中可以打开 Plugins 浏览和安装插件；CLI 中也可以打开插件列表。
- 安装时可能需要外部服务授权，有些插件会在首次使用时才请求登录。
- 安装后可以直接描述任务，让 Codex 自行选择工具；也可以用 @ 明确指定插件或技能。
- 如果只想关闭插件，可以在配置中把对应插件设置为 disabled。

## 实践补充

- 新装插件后新开线程测试。
- 先做总结、读取、检查等只读任务。
- 写入、发送、删除、发布类任务要单独确认。

## 推荐工作流

1. 先明确任务目标、输入来源和允许 Codex 使用的工具。
2. 让 Codex 输出计划、风险边界和需要你确认的问题。
3. 从小范围样例开始，确认方向后再扩大。
4. 要求 Codex 保留证据、文件路径、截图、命令输出或验证结果。
5. 对发送、删除、付款、发布、提交、部署等动作保持人工确认。

## 示例提示词

```text
请使用已安装插件完成一个只读测试：读取指定来源，生成摘要和来源列表。不要写入、删除、发送或修改任何外部系统内容。
```
