# 插件概览

![Codex 插件目录](https://md-1251009918.cos.ap-shanghai.myqcloud.com/hackstart/codex-docs/images-codex-plugins-directory.webp)

插件把 skills、app 集成和 MCP server 打包成可安装能力。

## 官方内容整理

- 插件把 skills、app 集成和 MCP server 打包成可安装能力。
- 插件可以扩展 Codex 的工作流，例如安全扫描、Gmail、Google Drive、Slack、Sites 等。
- 插件可能包含技能、外部 App 连接和 MCP server。
- 插件目录会按来源分组，包括官方精选、分享给你的插件、你创建的插件。

## 实践补充

- 插件不是越多越好，应围绕真实任务安装。
- 先用只读任务测试插件，再允许写操作。
- 外部 App 仍受自身授权、隐私和数据共享政策约束。

## 推荐工作流

1. 先明确任务目标、输入来源和允许 Codex 使用的工具。
2. 让 Codex 输出计划、风险边界和需要你确认的问题。
3. 从小范围样例开始，确认方向后再扩大。
4. 要求 Codex 保留证据、文件路径、截图、命令输出或验证结果。
5. 对发送、删除、付款、发布、提交、部署等动作保持人工确认。

## 示例提示词

```text
请判断这个任务需要哪些 Codex 插件。按必要性排序，说明每个插件提供什么能力、需要什么授权、风险在哪里，以及第一个测试任务怎么写。
```
