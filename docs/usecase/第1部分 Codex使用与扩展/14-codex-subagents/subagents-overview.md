# Subagents 概览

Subagents 允许 Codex 显式生成多个专门代理并行工作，再把结果汇总到一个回答中。

## 官方内容整理

- Subagents 允许 Codex 显式生成多个专门代理并行工作，再把结果汇总到一个回答中。
- 它适合高度并行的复杂任务，例如代码库探索、多维 PR 审查、研究资料拆解和多方案比较。
- Codex 只会在你明确要求时生成 subagents。
- 每个 subagent 都会消耗自己的模型和工具资源，因此成本高于单代理。

## 实践补充

- 把任务拆成相互独立的子问题。
- 明确每个代理的关注点、输出格式和停止条件。
- 最后让主线程综合证据，而不是简单拼接结果。

## 推荐工作流

1. 先明确任务目标、输入来源和允许 Codex 使用的工具。
2. 让 Codex 输出计划、风险边界和需要你确认的问题。
3. 从小范围样例开始，确认方向后再扩大。
4. 要求 Codex 保留证据、文件路径、截图、命令输出或验证结果。
5. 对发送、删除、付款、发布、提交、部署等动作保持人工确认。

## 示例提示词

```text
请为当前 PR 启动 subagent 工作流：分别检查安全、正确性、测试缺口、性能、可维护性。每个 subagent 独立输出发现，全部完成后汇总成按严重程度排序的报告。
```
