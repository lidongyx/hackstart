# MCP 集成

MCP 让 Codex 连接外部工具、私有数据源和自定义服务。App、CLI 和 IDE Extension 共享 MCP 设置。

## 官方内容整理

- MCP 让 Codex 连接外部工具、私有数据源和自定义服务。App、CLI 和 IDE Extension 共享 MCP 设置。
- MCP server 可以提供工具、资源或提示模板。
- App 设置中可以启用推荐服务器，也可以添加自定义服务器。
- 如果 MCP 需要 OAuth，App 会启动授权流程。
- 插件可能已经包含 MCP，此时优先通过插件安装和管理。

## 实践补充

- 先做只读测试，再考虑写操作。
- 区分个人授权和团队共享配置。
- 授权范围越小越好，特别是 Notion、Slack、GitHub、数据库等私有系统。

## 推荐工作流

1. 先明确任务目标、输入来源和允许 Codex 使用的工具。
2. 让 Codex 输出计划、风险边界和需要你确认的问题。
3. 从小范围样例开始，确认方向后再扩大。
4. 要求 Codex 保留证据、文件路径、截图、命令输出或验证结果。
5. 对发送、删除、付款、发布、提交、部署等动作保持人工确认。

## 示例提示词

```text
请帮我规划当前项目需要哪些 MCP。按必须、可选、暂不建议分类，并说明每个 MCP 提供什么工具、需要什么授权、有哪些安全边界。
```
