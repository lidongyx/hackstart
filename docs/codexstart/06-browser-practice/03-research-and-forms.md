# 案例：从公开网页整理一份资料表

## 任务目标

从公开网页收集 10 条条目，整理为 CSV 或 Markdown 表格。每条记录要包含名称、来源、日期、关键事实和原始链接。

## 可靠流程

1. 先确定字段和纳入标准。
2. 先采集 2 条样本并核对来源。
3. 再批量整理剩余条目。
4. 对缺失字段标记“未找到”，不要猜测补全。
5. 输出来源和采集日期。

## 表单练习的边界

可以在测试站点或本地页面练习输入和校验。涉及真实账号、发送、下单、付款、发布评论或提交申请时，必须在最后一步暂停确认。

```text
可以填写测试表单，但不要点击最终提交。
提交前列出字段、拟提交内容和可能产生的外部影响，等待我的明确确认。
```

## 课后任务

做一份“课程资源清单”，至少包含 10 条来源，并人工抽查 3 条原始页面。记录哪些信息是直接事实，哪些只是你的分类判断。
