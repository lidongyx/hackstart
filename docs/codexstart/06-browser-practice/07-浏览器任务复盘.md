# 浏览器任务复盘

## 练习目标

本章把前面学到的 Codex 方法放进一个更完整的工作场景，重点练习边界、过程记录和交付验收。

## 建议流程

1. 先阅读现有项目上下文，确认输入、输出和不能做的事情。
2. 让 Codex 给出计划与风险，再按阶段执行。
3. 用一个真实但脱敏的样例完成练习，保留过程证据。
4. 在交付前检查正常路径、失败路径和移动端或不同文件格式下的结果。

## 验收清单

- [ ] 任务范围清晰，关键决定有记录。
- [ ] 结果可以被另一个人复查。
- [ ] 失败时知道如何定位和回滚。
- [ ] 写下下一次可以复用的模板或检查项。
