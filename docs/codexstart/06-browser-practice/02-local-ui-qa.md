# 案例：给本地网页做一次完整验收

## 前置准备

准备一个可以本地打开的网页，启动开发服务器后记录地址。不要直接把生产网站当作第一次练习对象。

## 验收流程

```text
请对本地网页做一次 UI 验收：
1. 桌面宽度打开首页，记录页面标题和首屏主要操作；
2. 点击所有主要导航，确认没有死链；
3. 测试空状态、错误输入和刷新后的状态；
4. 在手机宽度检查文字、按钮、表格和弹窗是否溢出；
5. 查看控制台和网络错误；
6. 输出按严重程度排序的问题清单，不要直接修改。
```

## 问题报告格式

```text
严重程度：P0 / P1 / P2
页面和入口：
复现步骤：
期望结果：
实际结果：
证据：截图或错误信息
建议修复：
```

先报告、后修复，能防止 Codex 把测试过程和修改过程混在一起，也方便你判断它是否真的复现了问题。

## 课后任务

选择一个你自己的页面，产出一份至少包含 5 个检查点的 UI 验收报告。只修复 P0/P1，修复后重新跑完整流程。
