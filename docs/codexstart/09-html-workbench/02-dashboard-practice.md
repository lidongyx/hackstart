# 实战：做一个个人工作台首页

## 第一版只做四块

1. 今日任务。
2. 常用入口。
3. 最近资料。
4. 状态摘要。

每一块都要有明确用途，不要先堆很多卡片。页面的价值是让你更快进入工作，而不是展示更多装饰。

## 推荐任务卡

```text
请创建一个本地个人工作台首页。
先设计信息架构和数据字段，再实现页面。
要求：
- 首屏能看到今日最重要的 3 件事；
- 任务可以标记完成并按优先级筛选；
- 常用入口支持搜索；
- 页面在手机和桌面都能使用；
- 使用 localStorage，不接后端；
- 不使用渐变大背景和无意义装饰。
完成后用浏览器检查空状态、长标题、窄屏和刷新。
```

## 迭代顺序

先完成信息结构，再完成核心交互，最后处理视觉细节。每次迭代都保留可打开版本，避免一次改动把所有功能一起弄坏。

## 课后任务

增加一个“本周复盘”区域，展示完成任务数、未完成任务数和三个需要下周处理的问题。数据来源要写清楚。
