# HTML 即一切

## 为什么 HTML 适合做工作交付

HTML 文件几乎不需要复杂环境就能打开，既可以呈现文字、表格、图表、图片和音频，也可以加入搜索、筛选、折叠、计算和导出功能。对很多个人工作来说，它是连接“资料”和“工具”的最低成本载体。

## 能做什么

- 把一份长报告做成可搜索的阅读页面。
- 把 CSV 做成带筛选和排序的看板。
- 把会议记录做成行动项追踪器。
- 把学习资料做成带进度的课程页面。
- 把多个常用链接、命令和模板放在个人工作台。

## 最小工作台结构

```text
workbench/
  index.html
  styles.css
  app.js
  data/
  assets/
  README.md
```

先用静态文件做出可运行版本，再决定是否需要数据库、账号和后端。很多需求并不需要一开始就上复杂框架。

## 课后任务

把你每天打开的 5 个页面、3 个文件和 3 个命令整理成一个静态 HTML 首页，先不做登录和云同步。
