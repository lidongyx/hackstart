# 实战：把报告变成交互页面

## 适合改造成 HTML 的内容

- 长文档中的章节和术语。
- 有很多行的指标表。
- 需要比较不同时间或类别的数据。
- 需要同时展示结论、证据和原始来源。

## 页面功能建议

- 搜索关键词。
- 按标签或日期筛选。
- 展开查看证据。
- 一键复制引用。
- 导出当前筛选结果。

## 提示词

```text
请把 report.md 改造成一个可离线打开的 HTML 报告。
保留原文事实，不改变数字。
增加目录、关键词搜索、标签筛选、证据折叠和来源链接。
页面底部显示生成日期、数据范围和已知限制。
先列出数据结构和交互设计，再开始实现。
```

## 验收重点

- 筛选后数字和列表是否一致。
- 搜索是否覆盖标题、正文和标签。
- 折叠内容是否仍然可访问。
- 离线打开时是否依赖失效的外部资源。

## 课后任务

选一份你已经写过的周报，做成可搜索 HTML，并为每个关键数字加上来源字段。
