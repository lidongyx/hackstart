# 复核与验收：最后一公里由你负责

## 三层验收

### 结构验收

文件是否在正确位置，命名是否符合约定，依赖和配置是否完整。

### 行为验收

正常流程、空状态、错误输入、刷新、返回和重复操作是否都符合预期。

### 结果验收

内容是否准确，数字是否一致，视觉是否可读，外部动作是否真的产生了预期结果。

## 交付前提示词

```text
请把这次任务当作一次正式交付，而不是继续开发。
输出一份验收报告，包含：
1. 需求逐条对应的结果；
2. 实际修改的文件；
3. 执行过的命令或操作；
4. 通过和失败的检查；
5. 尚未覆盖的边界情况；
6. 我必须人工确认的事项。
如果有一项没有证据，不要写成“已完成”。
```

## 什么时候不能直接接受结果

- 任务涉及真实用户、真实付款或真实发送。
- 任务改变生产配置、权限、域名、证书或数据库。
- 结果包含法律、医疗、财务等高风险判断。
- 数据来自无法核实的网页或用户上传文件。
- Codex 修改了超出约定范围的内容。

## 课后任务

为你的阅读清单或个人工作台写一份 10 项验收清单，并让 Codex 根据清单执行一次自检。你负责抽查其中至少 3 项。
