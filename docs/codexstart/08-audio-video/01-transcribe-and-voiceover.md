# 音视频案例：转写与旁白

## 内容生产链

```text
音频/视频 -> 转写 -> 校对 -> 脚本 -> 旁白 -> 字幕 -> 复核
```

每一步的输出都要能独立检查。不要把自动转写直接当成最终稿，专有名词、人名、数字和时间轴尤其需要人工抽查。

## 转写提示词

```text
请转写这段音频，并按时间顺序输出。
要求：
- 尽量区分说话人；
- 对听不清的地方标记 [听不清 00:12]；
- 专有名词不要猜测，列入待核对清单；
- 另外生成一份行动项摘要，但不要把推断写成原话。
```

## 旁白提示词

```text
请把这份脚本整理成 45 秒中文旁白稿。
语气自然、短句优先，每句适合一次呼吸。
保留产品名和数字，不添加原稿没有的承诺。
输出：旁白稿、停顿建议、需要人工确认的专有名词。
```

## 课后任务

找一段 1 到 3 分钟的无敏感音频，完成转写、人工抽查、旁白稿和字幕文本四个文件。
