# 案例：整理一个混乱的资料文件夹

## 目标

把练习目录中的文件整理为：

```text
archive/
  documents/
  images/
  spreadsheets/
  needs-review/
index.csv
```

不要删除任何文件，不要覆盖同名文件，不要凭文件名猜测内容后直接丢弃资料。

## 推荐流程

1. 盘点文件名、大小、类型和修改时间。
2. 识别重复文件和无法判断的文件。
3. 先生成归档计划和预览表。
4. 选择 3 个样本执行移动。
5. 检查样本结果后再批量执行。
6. 生成索引并抽查。

## 提示词

```text
请整理练习目录中的文件。
第一阶段只读：输出文件清单、建议分类、重复项和不确定项。
第二阶段生成 archive-plan.csv，不移动任何文件。
等我确认后，先移动 3 个样本并验证。
只有样本验证通过，才能继续批量移动。
任何同名文件都放入 needs-review，不覆盖、不删除。
```

## 验收清单

- [ ] 原目录没有文件被静默删除。
- [ ] 每个移动文件都有旧路径和新路径。
- [ ] 重复项单独列出。
- [ ] 不确定项没有被强行分类。
- [ ] `index.csv` 可以被表格软件打开。
