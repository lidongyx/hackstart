# 案例：用原生应用完成一份可交付资料

## 练习选择

可以使用文本编辑器、表格软件或演示文稿应用，完成以下低风险任务：

- 打开练习数据。
- 按要求格式化。
- 导出为指定格式。
- 重新打开导出的文件核对。

不要使用真实客户信息、公司财务数据或未公开材料。

## 分阶段提示词

```text
请在本地办公软件中处理练习文件。
先确认当前打开的应用、文件名和保存位置。
只允许修改练习文件，不要操作其他窗口。
完成格式化后先保存为新文件，不覆盖原文件。
导出后重新打开新文件，检查标题、表格列数、日期格式和文件大小。
遇到弹窗、权限请求或保存路径变化时暂停。
```

## 为什么要“重新打开核对”

很多办公软件导出时会改变字体、分页、公式或媒体资源。保存成功只代表文件写入，不代表交付效果正确。重新打开是最便宜的回归测试。

## 课后任务

将一份练习 Markdown 资料做成 PDF 和 DOCX 两个版本，并让 Codex 列出两种格式的差异和无法自动确认的地方。
