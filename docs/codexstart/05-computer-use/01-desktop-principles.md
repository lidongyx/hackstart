# 让 Codex 操作电脑的基本原则

## 电脑操作不只是点击

一次电脑操作通常包含：识别当前界面、判断目标控件、执行动作、读取反馈、决定下一步。任何一步识别错误，都可能把正确任务带偏。

## 四条底线

1. 先让 Codex 描述当前界面，再让它点击。
2. 先做可逆动作，再做不可逆动作。
3. 批量动作先用一个样本演练。
4. 涉及发送、删除、支付、权限和生产数据时暂停确认。

## 电脑操作提示词

```text
请操作当前桌面完成以下任务，但遵守这些边界：
- 先截图或读取当前界面并说明你看到的内容；
- 只操作名为“练习资料”的文件夹；
- 不打开密码管理器、银行、邮箱和即时通信应用；
- 不删除文件，不发送内容，不提交表单；
- 每完成一步说明结果；
- 如果界面与预期不同，立即暂停并告诉我。
```

## 什么时候应该改用命令行或 API

当任务是批量重命名、读取结构化数据、生成报告或重复执行时，命令行和 API 通常比鼠标操作更稳定。电脑操作适合需要真实桌面状态、文件选择器、原生应用或视觉确认的场景。

## 课后任务

在一个专门的练习文件夹里，让 Codex 把三份无敏感信息的文本文件按主题移动到子目录。要求先列计划，完成后报告每个文件的去向。
