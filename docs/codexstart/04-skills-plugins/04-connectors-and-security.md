# 连接器与权限边界

## 三个概念不要混淆

- **MCP** 更像工具接口，让 Codex 调用搜索、浏览器、设计或内部系统能力。
- **App Connector** 更像账号授权，让 Codex 访问某个应用里的数据。
- **Plugin** 是能力打包和分发单位，可以包含 Skill、MCP、连接器说明和界面信息。

安装插件不等于已经登录外部应用，也不等于自动获得所有写权限。

## 最小权限策略

| 场景 | 起步权限 | 稳定后再考虑 |
| --- | --- | --- |
| 文档查询 | search / read | 无需写权限 |
| 浏览器检查 | open / screenshot | click / type |
| GitHub | read issue / PR | 评论、合并、修改 |
| 邮件 | 搜索和草拟 | 发送 |
| 数据库 | 查询 | 更新、删除 |

## 连接外部账号前的提示词

```text
在连接外部应用前，请先说明：
- 需要读取哪些数据；
- 是否需要写权限；
- 哪些操作会产生外部影响；
- 如何撤销授权；
- 有没有不连接账号的替代方案。
```
