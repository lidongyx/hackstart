# 毕业项目：你的个人工作台

## 项目目标

做一个本地优先的个人工作台，至少包含：

- 今日任务与完成状态。
- 常用链接和文件入口。
- 一份可搜索的知识或资料列表。
- 本周复盘摘要。
- 一个“让 Codex 继续工作的任务说明”入口。

## 推荐里程碑

### 里程碑 1：可打开

HTML 能直接打开，内容结构清楚，手机和桌面都不溢出。

### 里程碑 2：可操作

任务新增、完成、筛选和本地保存都能工作。

### 里程碑 3：可复用

数据结构、提示词和验证命令写进 README，别人可以接手。

### 里程碑 4：可扩展

把“每日简报”或“周复盘”流程沉淀成 Skill，再考虑连接外部数据。

## 毕业项目提示词

```text
请把当前目录做成一个个人工作台项目。
先阅读现有文件并给出信息架构、数据结构、里程碑和风险。
每完成一个里程碑先停下来汇报，不要跨过检查点。
优先保证本地可用、数据可理解、失败可恢复。
涉及外部账号、消息发送、线上部署和删除动作时必须暂停确认。
最终交付 README、验收清单、已知限制和下一步计划。
```

## 课后任务

完成至少两个里程碑，并邀请一个没有参与制作的人按验收清单使用 10 分钟。记录他找不到入口、看不懂字段或无法完成的地方。
