# 结课自测与下一步

## 你应该能回答

1. 什么信息应该写进 Prompt，什么信息应该写进 `AGENTS.md`？
2. Skill 和 Plugin 的边界是什么？
3. 什么时候用 Browser，什么时候用 Chrome 或 Playwright？
4. 哪些电脑操作必须先人工确认？
5. 如何让 Agent 在长任务中停下来汇报？
6. 为什么办公文件生成后还要重新打开或渲染检查？
7. HTML 工作台什么时候比数据库应用更合适？
8. 怎样把一个重复 Prompt 逐步升级成稳定工作流？

## 最终验收

请让 Codex 对你的毕业项目执行一次完整验收，并要求它提供：

- 需求与实现对照表。
- 实际文件清单。
- 浏览器或命令行验证记录。
- 已知限制和失败路径。
- 外部影响和权限说明。
- 下一版只选 3 个最重要的改进。

## 继续学习的方向

- 阅读 `插件与技能实践小册`，深入学习 Skill、Plugin、MCP 和安装管理。
- 阅读 `Codex案例`，按真实工作场景练习办公、工程、设计和质量保障。
- 把毕业项目中的稳定流程拆成 Skill、CLI 或团队插件。
- 用低风险数据先跑通，再逐步连接真实工具和账号。

完成这套课的标志，不是记住了多少术语，而是你能把一个模糊目标变成可执行、可验证、可复用的工作流程。
