# 办公自动化案例：表格到报告

## 先定义数据契约

在处理表格前，先明确：

- 每一行代表什么。
- 日期、金额和空值如何处理。
- 重复记录如何识别。
- 哪些列可以计算，哪些列只能原样保留。
- 最终指标的公式和单位是什么。

## 推荐工作流

```text
1. 读取表头、行数、空值和异常格式。
2. 输出数据质量报告，不修改原始文件。
3. 复制到工作文件，记录清洗规则。
4. 生成指标和图表。
5. 用样本手工复算 3 个关键结果。
6. 生成面向读者的报告，并附方法说明。
```

## 提示词

```text
请分析这份练习表格，但不要覆盖原文件。
先输出：行数、列名、空值、重复项、日期范围和明显异常。
再提出清洗规则，等待确认后执行。
报告中的每个关键数字都要写出来源列和计算公式。
不要把缺失值当成 0，除非有明确业务规则。
```

## 课后任务

做一份“月度预算 vs 实际”报告，要求同时输出：数据质量说明、指标表、一个图表和三条基于数据的观察。把推断和事实分开写。
