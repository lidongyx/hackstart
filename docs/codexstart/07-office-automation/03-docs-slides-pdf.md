# 文档、幻灯片与 PDF 的办公流水线

## 不同格式有不同验收方式

- 文档：检查标题层级、目录、页眉页脚和分页。
- 幻灯片：检查每页信息密度、对齐、字体和演讲顺序。
- PDF：检查页面是否缺失、字体是否替换、图片是否模糊、链接是否可用。

## 推荐提示词

```text
请把这份资料整理成 8 页演示文稿。
先给出每页标题、核心信息、证据来源和视觉建议，不要生成文件。
确认后再生成可编辑版本。
生成后逐页渲染或截图检查：文字溢出、表格截断、字号、对齐和空白页。
输出文件路径、每页检查结果和无法自动判断的内容。
```

## 关键原则

内容正确不代表版式合格。办公自动化必须包含“生成 -> 渲染 -> 视觉检查 -> 修改 -> 再渲染”这一闭环。

## 课后任务

选一篇短文章做成 5 页演示文稿，同时保留一份 Markdown 讲稿。检查每页是否只有一个主要结论。
