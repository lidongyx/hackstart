# 办公自动化案例：会议到行动项

## 输入和输出

输入可以是会议文字稿、人工笔记或导出的聊天记录。输出建议分成三层：

1. **决策**：已经确定了什么。
2. **行动项**：谁在什么时候之前做什么。
3. **待确认**：哪些问题还不能当成事实。

## 推荐提示词

```text
请把这份会议记录整理成行动表。
要求：
- 不补写记录中没有出现的事实；
- 把决定、讨论观点和待确认问题分开；
- 每个行动项包含负责人、截止日期、依赖和原文依据；
- 没有明确负责人的任务标记为“待分配”；
- 最后列出需要人工确认的 5 个问题。
输出 Markdown 表格和一段 150 字以内摘要。
```

## 验收重点

- 行动项是否真的来自原文。
- 负责人和日期是否被误推断。
- 决策是否和建议混在一起。
- 摘要是否遗漏争议点。

## 课后任务

把行动表再转换成一份周计划，并要求 Codex 保留每条任务的原始依据，避免计划在整理过程中失去来源。
