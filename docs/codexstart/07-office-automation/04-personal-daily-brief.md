# 案例：生成个人每日简报

## 简报结构

```text
今日必须完成
需要等待或跟进
日程冲突与风险
昨天的未完成事项
今天适合推进的深度工作
```

## 自动化边界

Codex 可以读取和汇总你的资料，也可以生成草稿；发送给同事、修改日历、移动任务和关闭事项，先保留人工确认。

## 提示词

```text
请根据今天的任务清单和日程生成个人简报。
只使用输入资料中的事实；把你的推断单独放在“建议”部分。
优先标记截止时间临近、依赖他人和可能冲突的事项。
不要改动任务、日历或发送任何消息。
最后给我 3 个需要人工决定的问题。
```

## 课后任务

连续 3 天使用同一模板，比较哪些字段最有帮助，再把稳定的字段和规则沉淀成一个 Skill。
