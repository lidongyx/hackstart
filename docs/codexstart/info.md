# CodexStart 零基础课程

这本小册面向第一次使用 Codex 的学习者，从任务卡、上下文、权限和验收开始，逐步进入 Agent、插件、浏览器、办公自动化和个人工作流。

## 学习方式

- 先从目录选择当前最需要解决的问题，不要求一次读完。
- 每章都配一个可以在本地完成的练习或检查清单。
- 把有效的提示词、过程记录和验收标准沉淀成自己的工作模板。
- 涉及发送、删除、付款、部署或真实账号时，保留人工确认。

## 课程结果

完成后，你应该能够把一个模糊任务改写成可执行任务卡，给 Codex 准备合适的上下文，按阶段完成交付，并用证据检查结果是否真的可用。
