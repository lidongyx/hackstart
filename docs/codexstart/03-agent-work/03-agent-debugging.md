# Agent 调查一个真实问题

## 案例：页面在手机上被截断

把问题交给 Codex：

```text
移动端页面右侧出现横向滚动。
请按调查流程处理：
1. 先在 390px 宽度复现并记录截图；
2. 检查可能造成溢出的元素和计算样式；
3. 列出候选原因和证据；
4. 只选择最小修复；
5. 再测 390px、768px 和桌面宽度；
6. 输出根因、改动和回归结果。
不要用全局 overflow-x:hidden 掩盖问题，除非能证明它符合页面设计。
```

## 为什么这个案例适合练 Agent

它没有单一的“正确代码”，而是要求 Agent：

- 使用浏览器和开发者工具观察事实。
- 形成可被证据支持的假设。
- 控制修复范围。
- 在多个视口回归。
- 解释为什么没有采用更粗暴的方案。

## 复盘问题

任务完成后继续问：

```text
复盘这次调查：
- 哪一步最耗时；
- 哪个证据最有价值；
- 哪条规则可以写进项目说明；
- 哪个检查可以做成自动化脚本或 Skill；
- 下次如何更早发现同类问题。
```

## 课后任务

把案例中的“移动端溢出”换成一个你自己的真实问题，保留同样的调查结构，不要直接要求 Codex 重写整个项目。
