# 并行任务与子任务

## 适合并行的工作

当任务之间输入和写入范围互不冲突时，可以并行：

- 一个人检查文档链接，另一个人检查代码格式。
- 一个任务整理会议记录，另一个任务制作数据摘要。
- 一个任务做桌面截图，另一个任务做移动端截图。
- 一个任务阅读 API 文档，另一个任务盘点现有调用点。

并行前要写清每个子任务的输出格式和禁止修改的范围。

## 不适合并行的工作

- 多个任务同时修改同一组件。
- 设计决策还没确定就开始实现。
- 后一步依赖前一步的文件结构。
- 多个任务会发送、删除、部署或修改线上配置。

## 子任务模板

```text
子任务：检查 docs 目录中的死链接
输入：只读取 docs/ 和 docusaurus.config.ts
输出：CSV 或 Markdown 表格，包含文件、链接、状态和建议
禁止：不要修改文件，不要访问需要登录的站点
完成标准：抽样核对 5 条结果，并说明无法确认的链接
```

## 课后任务

为“发布一个个人网站”设计 3 个可以并行的只读子任务，再设计 2 个必须串行的写入任务，并说明原因。
