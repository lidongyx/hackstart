# HackStart Workshop

HackStart Workshop 面向没有编程基础、但希望把 AI 用进日常工作的新人。每个 Workshop 都是一项完整任务：准备一份真实但已脱敏的输入，使用 Codex 协调工具完成产出，检查结果，再把过程和成果提交到社区。

## 参加方式

1. 从目录选择一个 Workshop。
2. 按文档完成一个从输入到交付的任务，不要求把所有工具学完。
3. 在“我的任务”中提交一段过程记录和至少一张成果截图。
4. 勾选完成后，打卡会直接同步到 HackStart 社区。

Workshop 的重点不是展示“AI 生成过什么”，而是让别人可以复查：你用了什么输入、如何判断结果可用、哪里仍然需要人工确认。

## 打卡边界

- 只使用你有权处理的文件、图片和数据。
- 客户姓名、邮箱、电话、订单号、报价和内部链接先替换成示例值。
- 不要把 API Key、Cookie、支付信息或公司内部密码放进截图和打卡文字。
- 成果可以不完美，但必须写清楚你验证了什么、还没有验证什么。
