# 用 Codex + Remotion + HyperFrames 生成短视频

这是一个面向视频剪辑、课程运营和内容团队新人的视频 Workshop。你会把一个主题拆成脚本、镜头和素材，再让 Codex 协调 Remotion 与 HyperFrames 完成一条 30-60 秒的短视频。

## Workshop 参数

| 参数 | 内容 |
| --- | --- |
| 难度 | 进阶，3 / 5 |
| 预计操作时间 | 120-180 分钟 |
| 最终成果 | 一条 MP4 视频、镜头表、可复用工程目录和验收记录 |
| 需要准备 | 一个办公技巧、产品功能或活动主题，3-8 个有权使用的素材 |
| 工具 | Codex、Remotion、HyperFrames、现有图片或音频素材 |

本 Workshop 不要求先学会所有视频软件。目标是跑通一条从主题到成片的可重复工作流：输入明确、时间线可读、渲染可重做、成片有人检查。

## 你要完成的事情

1. 写出 30-60 秒脚本和镜头表。
2. 用 Codex 建立 Remotion / HyperFrames 工程结构。
3. 完成画面、字幕、节奏和音频的第一版。
4. 渲染桌面端和手机端预览，检查可读性与节奏。
5. 提交成片、镜头表、工程截图和一次复盘。
