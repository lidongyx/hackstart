# 02 生成双语上架资料

根据事实表生成一套结构一致的中英双语资料。英文不是逐字翻译练习，要保证规格、单位、数量和条件与中文事实一致。

## 推荐交付结构

```md
# 产品标题 / Product title

## 一句话简介 / One-line description

## 主要卖点 / Key benefits

## 规格 / Specifications

## 适用客户 / Suitable for

## 包装与交付 / Packaging and delivery

## 常见问题 / FAQ

## 待确认信息 / To be confirmed
```

## 给 Codex 的生成任务

```text
根据已经确认的产品事实，生成中英双语上架资料。

要求：
- 标题、规格、单位、数量和条件必须逐项对应。
- 只写已确认事实；待确认内容单独列出，不能伪装成卖点。
- 英文自然、简洁，适合采购人员快速阅读。
- 不使用绝对化承诺，例如“100%”“绝对无风险”“永久有效”，除非资料中有证据。
- FAQ 至少覆盖规格、定制、包装、交付和售后五个方向。
```

## 逐项核对

随机选择 10 个规格、数字或条件，对照事实表检查中英文两侧是否一致。发现不一致时，先修正资料源或提示词，再生成下一版。

## 通过标准

- 双语资料结构一致，读者不需要来回猜字段对应关系。
- 所有数字和条件都能追溯到事实表。
- FAQ 没有擅自承诺价格、库存、认证或交期。
