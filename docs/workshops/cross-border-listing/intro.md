# 用 Codex 做一份外贸产品上架包

这是一个面向外贸业务员、跨境电商运营和独立卖家的实战 Workshop。你会从一份脱敏产品资料出发，让 Codex 产出一套可以交给设计、销售和客服继续使用的上架材料。

## Workshop 参数

| 参数 | 内容 |
| --- | --- |
| 难度 | 入门，2 / 5 |
| 预计操作时间 | 90-120 分钟 |
| 最终成果 | 中英双语产品资料、3 类询盘回复和跟进表 |
| 需要准备 | 一个产品的规格、卖点、交付范围和常见问题 |
| 工具 | Codex、表格或文档编辑器 |

不要把 Workshop 变成“把中文翻成英文”。最终结果必须把事实、卖点、适用客户和下一步沟通分开，并标出不能确认的内容。

## 你要完成的事情

1. 整理产品事实和禁止虚构的边界。
2. 生成中英双语标题、简介、规格和 FAQ。
3. 生成首次回复、报价前澄清和跟进三类模板。
4. 用一个虚构询盘测试回复是否能推动下一步。
5. 提交一份可交接给运营或销售的上架包。
