# 04 验收与提交打卡

最后请一位同事只看上架包，不看你的生成过程，回答三个问题：产品是什么、客户下一步要提供什么、哪些信息仍然不能承诺。如果回答不出来，优先改结构和字段，不要只加更多形容词。

## 验收清单

- [ ] 中文和英文的产品事实、数字和单位一致。
- [ ] 已确认、待确认和缺失信息有明确区分。
- [ ] FAQ 覆盖规格、定制、包装、交付和售后。
- [ ] 三类询盘回复都有明确下一步。
- [ ] 跟进表有状态、负责人或截止时间。
- [ ] 文档中没有真实客户身份、邮箱、电话、报价或内部供应商信息。

## 最终交付模板

```md
## 上架包
- 产品和目标客户：
- 双语资料：
- FAQ：

## 询盘跟进
- 我准备的三类回复：
- 必须先确认的五个问题：
- 跟进表字段：

## 复盘
- Codex 帮我节省的时间：
- 我人工核对的字段：
- 仍然不能自动化的判断：
```

提交脱敏后的上架资料截图、询盘回复摘要和跟进表截图。通过标准是销售或运营同事可以接着使用，而不是只得到一段看起来流畅的英文。
