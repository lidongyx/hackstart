# 用 Codex + GPT Image 2.5 做视觉素材包

这是一个面向内容运营、电商和品牌新人的视觉 Workshop。你会先用 Codex 把模糊需求变成视觉 brief，再使用当前 Codex 环境中的 GPT Image 2.5 生成一套有明确用途和尺寸的素材，最后完成人工检查。

## Workshop 参数

| 参数 | 内容 |
| --- | --- |
| 难度 | 入门，2 / 5 |
| 预计操作时间 | 90-120 分钟 |
| 最终成果 | 1 张主视觉、2 个适配版本、1 份提示词和验收记录 |
| 需要准备 | 一个产品、活动或内容主题，最好有公开可使用的参考素材 |
| 工具 | Codex、GPT Image 2.5、图片预览或简单编辑工具 |

不要把任务理解为“多生成几张图”。你要交付的是一组能放进具体工作流的素材，并能说明哪一张用于什么场景。

## 你要完成的事情

1. 写清受众、用途、画幅、主体和不能出现的元素。
2. 让 Codex 把 brief 转成可执行的图像提示词和检查表。
3. 使用 GPT Image 2.5 生成主视觉，并制作两个尺寸或构图变体。
4. 检查主体、文字、品牌边界和尺寸是否适合发布。
5. 提交图片、提示词和一次失败迭代的复盘。
