# 03 验收与提交打卡

先把飞书报告分享给一位不了解数据处理过程的人，只给他 60 秒回答：核心变化是什么、下一步建议是什么、哪些地方还不确定。记录他看不懂的地方并调整标题或说明。

## 验收清单

- [ ] 原始数据已经脱敏，链接权限符合预期。
- [ ] 关键指标有公式、口径、时间范围和来源。
- [ ] 至少两张图表与原始数据抽查一致。
- [ ] 图表标题写明对象、时间和单位。
- [ ] 结论区分事实、解释和行动建议。
- [ ] 写出至少一个不能仅凭当前数据回答的问题。

## 最终交付模板

```md
## 数据问题
- 我想回答的问题：
- 数据范围：
- 数据来源：

## 结果
- 最重要的三个指标：
- 最明显的变化：
- 下一步行动：

## 验证
- 我抽查的图表：
- 发现并修正的问题：
- 当前数据不能证明的结论：
```

提交飞书报告的脱敏截图、指标字典摘要和过程记录。不要在截图中暴露真实姓名、客户编号、内部链接或未公开经营数据。
