# 用 Codex + 飞书做一页数据可视化

这是一个面向运营、销售和管理汇报新人的数据 Workshop。你会用 Codex 整理一份小型 CSV 或表格数据，再把清洗规则、关键指标和图表放进飞书文档或表格，形成一页可以继续协作的报告。

## Workshop 参数

| 参数 | 内容 |
| --- | --- |
| 难度 | 入门，2 / 5 |
| 预计操作时间 | 90-120 分钟 |
| 最终成果 | 一页飞书数据报告、至少两张图表和行动建议 |
| 需要准备 | 20-100 行脱敏数据，或自拟销售、内容、客户跟进样例 |
| 工具 | Codex、飞书文档或飞书表格 |

报告不能只展示图表。每个指标都要能回答“发生了什么、为什么可能发生、下一步做什么”。

## 你要完成的事情

1. 让 Codex 检查字段、缺失值、重复值和口径冲突。
2. 确定 3-5 个指标和一个需要回答的业务问题。
3. 在飞书中建立数据表、图表和结论区。
4. 用原始数据抽查图表，避免图表与数字不一致。
5. 提交一页报告截图和可复查的口径说明。
