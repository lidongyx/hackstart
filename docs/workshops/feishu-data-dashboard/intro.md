# 用 Codex + 飞书做一页数据可视化

这是一个面向运营、销售和管理汇报新人的数据 Workshop。你会用 Codex 整理一份小型 CSV 或表格数据，再把清洗规则、关键指标和图表放进飞书文档或表格，形成一页可以继续协作的报告。

## Workshop 参数

| 参数 | 内容 |
| --- | --- |
| 难度 | 入门，2 / 5 |
| 预计操作时间 | 90-120 分钟 |
| 最终成果 | 一页飞书数据报告、至少两张图表和行动建议 |
| 需要准备 | 20-100 行脱敏数据，或自拟销售、内容、客户跟进样例 |
| 工具 | Codex、飞书文档或飞书表格 |

报告不能只展示图表。每个指标都要能回答“发生了什么、为什么可能发生、下一步做什么”。

## 你要完成的事情

1. 让 Codex 检查字段、缺失值、重复值和口径冲突。
2. 确定 3-5 个指标和一个需要回答的业务问题。
3. 在飞书中建立数据表、图表和结论区。
4. 用原始数据抽查图表，避免图表与数字不一致。
5. 提交一页报告截图和可复查的口径说明。

进入 [01 检查数据](#01-data) 开始。


<a id="01-data"></a>

## 01 检查数据与指标口径

先选一个问题，不要先选图表。例如：

- 哪些渠道带来的有效咨询最多？
- 哪些产品在最近几周转化率下降？
- 内容发布后，哪类主题最值得继续投入？

### 让 Codex 做数据体检

把脱敏后的数据文件放在一个单独目录，给 Codex 下面的任务卡：

```text
请先检查这份数据，不要直接做结论。
输出：
1. 字段名、类型、单位和可能的业务含义。
2. 缺失值、重复行、异常值和日期范围。
3. 可能混用的统计口径，例如“订单数”和“有效订单数”。
4. 适合回答的 3 个业务问题。
5. 每个问题建议使用的指标、分组和图表类型。

所有推断必须标记为“推测”，不要补写文件中没有的业务规则。
```

### 建立指标字典

把最终采用的指标写成一张小表：

| 指标 | 公式 | 时间范围 | 分组方式 | 数据来源 |
| --- | --- | --- | --- | --- |
| 有效咨询率 | 有效咨询数 / 总咨询数 | 本月 | 渠道 | 原始表字段 |

### 通过标准

- 数据已经脱敏，且能说明每一列的含义。
- 至少识别出一项数据质量问题或确认“未发现明显问题”的依据。
- 指标有公式、时间范围和来源，不使用模糊的“表现更好”。


<a id="02-feishu"></a>

## 02 在飞书中建立一页报告

把原始表和整理后的数据放进飞书表格或飞书文档。建议一页报告包含四个区域：

```text
标题和时间范围
关键指标卡（3-5 个）
图表（2-3 张）
结论、行动和待确认问题
```

### 图表选择

| 问题 | 优先图表 |
| --- | --- |
| 比较不同渠道或产品 | 条形图 |
| 观察时间变化 | 折线图 |
| 查看构成比例 | 堆叠条形图或饼图 |
| 查看两个指标关系 | 散点图 |

不要为了填满页面添加图表。每张图都要在标题中写清对象、时间和单位，例如“2026 年 9 月各渠道有效咨询数”。

### 用 Codex 生成图表配置建议

```text
基于已经确认的指标字典，为飞书报告设计 2-3 张图表。
每张图表输出：标题、横轴、纵轴、分组、单位、排序方式、要回答的问题。
如果一个图表可能误导读者，请说明风险并推荐替代方案。
```

### 飞书协作设置

- 原始数据和结论区分开，保留一份只读原始表。
- 在报告顶部写清数据更新时间和统计范围。
- 给图表旁边加一行“如何解读”，避免只剩视觉装饰。
- 只分享给需要的人，不把含有真实客户信息的文档设为公开链接。

### 通过标准

- 报告一页内能看懂，读者无需打开原始表才能理解结论。
- 每张图表都能追溯到一个指标和一组数据。
- 报告中有更新时间、统计范围和数据限制。


<a id="03-review"></a>

## 03 验收与提交打卡

先把飞书报告分享给一位不了解数据处理过程的人，只给他 60 秒回答：核心变化是什么、下一步建议是什么、哪些地方还不确定。记录他看不懂的地方并调整标题或说明。

### 验收清单

- [ ] 原始数据已经脱敏，链接权限符合预期。
- [ ] 关键指标有公式、口径、时间范围和来源。
- [ ] 至少两张图表与原始数据抽查一致。
- [ ] 图表标题写明对象、时间和单位。
- [ ] 结论区分事实、解释和行动建议。
- [ ] 写出至少一个不能仅凭当前数据回答的问题。

### 最终交付模板

```md
### 数据问题
- 我想回答的问题：
- 数据范围：
- 数据来源：

### 结果
- 最重要的三个指标：
- 最明显的变化：
- 下一步行动：

### 验证
- 我抽查的图表：
- 发现并修正的问题：
- 当前数据不能证明的结论：
```

提交飞书报告的脱敏截图、指标字典摘要和过程记录。不要在截图中暴露真实姓名、客户编号、内部链接或未公开经营数据。
