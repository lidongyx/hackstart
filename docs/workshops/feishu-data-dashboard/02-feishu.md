# 02 在飞书中建立一页报告

把原始表和整理后的数据放进飞书表格或飞书文档。建议一页报告包含四个区域：

```text
标题和时间范围
关键指标卡（3-5 个）
图表（2-3 张）
结论、行动和待确认问题
```

## 图表选择

| 问题 | 优先图表 |
| --- | --- |
| 比较不同渠道或产品 | 条形图 |
| 观察时间变化 | 折线图 |
| 查看构成比例 | 堆叠条形图或饼图 |
| 查看两个指标关系 | 散点图 |

不要为了填满页面添加图表。每张图都要在标题中写清对象、时间和单位，例如“2026 年 9 月各渠道有效咨询数”。

## 用 Codex 生成图表配置建议

```text
基于已经确认的指标字典，为飞书报告设计 2-3 张图表。
每张图表输出：标题、横轴、纵轴、分组、单位、排序方式、要回答的问题。
如果一个图表可能误导读者，请说明风险并推荐替代方案。
```

## 飞书协作设置

- 原始数据和结论区分开，保留一份只读原始表。
- 在报告顶部写清数据更新时间和统计范围。
- 给图表旁边加一行“如何解读”，避免只剩视觉装饰。
- 只分享给需要的人，不把含有真实客户信息的文档设为公开链接。

## 通过标准

- 报告一页内能看懂，读者无需打开原始表才能理解结论。
- 每张图表都能追溯到一个指标和一组数据。
- 报告中有更新时间、统计范围和数据限制。
