# Codex 与视频制作

从脚本、分镜、配音到渲染与发布，把一次性视频制作变成可复用的工程流程。

这本小册把一个真实方向拆成 8 个部分，每个部分包含 7 个章节。建议先浏览完整目录，再从当前最需要解决的问题开始。

## 学习方式

- 先准备一个真实但已经脱敏的练习素材。
- 每章都留下输入、过程、结果和验收记录。
- 把有效的提示词、模板和检查清单沉淀成自己的工作资产。
- 涉及外部账号、发布、付费或敏感资料时，保留人工确认。

## 适合谁

适合想把 Codex 放进 Codex 与视频制作 工作流的创作者、运营者、开发者和独立学习者。
